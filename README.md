# 🎮 Tic-Tac-Toe

A sleek, responsive, zero-dependency Tic-Tac-Toe web application built with vanilla HTML5, CSS3, and JavaScript. Features smooth state animations and built-in dark mode support.

**🔗 Play Live:** [https://anki-bot.github.io/Tic-Tac-Toe/](https://anki-bot.github.io/Tic-Tac-Toe/)

---

## ✨ Features
* **Dark Mode Support:** Seamless theme switching for comfortable viewing in any lighting environment.
* **Smooth Animations:** Fluid UI transitions for board moves, win-state highlights, and game resets.
* **Zero Dependencies:** Contained within a single lightweight HTML file for instant loading and portability.
